# Urdu Story Generation AI - Phase 1

## Overview
This project aims to collect and preprocess 400-500 high-quality Urdu stories for training a tokenizer.

## Structure
- `data/`: Raw and processed data
- `src/`: Source code for scraping and preprocessing
- `config/`: Configuration files
- `scripts/`: Execution scripts

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run scraper: `python scripts/run_scraper.py`
3. Run preprocessing: `python scripts/run_preprocessing.py`
