# Urdu Stories — React + Tailwind UI

Light-themed dashboard and chatbot UI (React 18, Vite, Tailwind CSS).

## Setup

```bash
npm install
```

## Run

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173). Use **Dashboard** and **Story Chat** from the nav.

## Build

```bash
npm run build
```

Output is in `dist/`.

## Stack

- **React 18** + **React Router 6**
- **Vite 5**
- **Tailwind CSS 3** (Dreelio-style palette in `tailwind.config.js`)
